Fake Sleep

Keep the terminal running while the display rests
Display rest mode

Turn the screen completely off while Dwella, the live data connection, and the auto-trader keep running. Start this only when the Mac is connected to power and you want to leave the terminal working unattended.

Ready — display on
macOS will request administrator approval, using Touch ID when available or your password.
How Fake Sleep works
Authorize & Start asks macOS to approve the sleep override. Dwella then disables system sleep for the session, starts a keep-awake assertion, and turns the display off. The live data connection and auto-trader continue while the screen is off. Click Restore system sleep when finished.
